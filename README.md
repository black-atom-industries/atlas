# atlas

> A book of destinations.

A desktop bookmark manager for developers. GUI app + CLI, built with [Tauri v2](https://tauri.app/).

Browse your bookmarks in Miller columns, search with a command palette, or manage them programmatically from the terminal. Invoke from anywhere with a global hotkey.

## Status

Pre-development. See the [epic](https://github.com/black-atom-industries/atlas/issues/1) for the full PRD.

## Tech Stack

| Layer | Technology |
|-|-|
| Runtime | [Deno](https://deno.com/) |
| App shell | [Tauri v2](https://tauri.app/) |
| Frontend | [React](https://react.dev/) 18 |
| State | [TanStack](https://tanstack.com/) Store + Query |
| Components | [Mantine](https://mantine.dev/) |
| Styling | CSS Modules |
| Build | [Vite](https://vite.dev/) 6 |
| Database | SQLite |

Successor to [bm](https://github.com/nikbrunner/bm), a Go-based TUI bookmark manager.
